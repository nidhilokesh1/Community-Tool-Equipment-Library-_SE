# Community Tool & Equipment Library

## Problem Statement

A neighborhood resource-sharing library where members can check out
power tools, camping gear, and lawnmowers, track deposit calculations,
manage return dates, and log damage assessments.

## Actors

- Community Member
- Library Custodian

## Project Objective

The system manages tool and equipment reservations, security deposits,
loan durations, returns, late fees, inventory availability and damage
assessment.

## Project Deliverables

1. Requirements Engineering
2. Architectural Diagram
3. Project Creation Screenshots
4. SRS and Work Breakdown Structure
5. GitHub Copilot
6. Software Testing

## Repository Structure

The project documents are organized into folders according to the
Software Engineering lab submission requirements.
